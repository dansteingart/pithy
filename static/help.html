🐍 pithy — collaborative python

A minimal, real-time collaborative Python editor. Code on the left, output on the right. Every URL is a page. Every page is a Python script.

Getting started

Go to pithy.steingart.ceec.echem.io/your_page_name. If it doesn't exist, it'll be created. If it does, you'll see the current code.

Avoid spaces and special characters in page names.

The pithy3 library

Start your code with:

from pithy3 import *

This gives you numpy, matplotlib/pylab, and:

FunctionWhat it does
showme()Render the current matplotlib figure to the output pane
showimg(pil_image)Render a PIL image
smooth(array, window_len)Moving average smoothing
clf()Clear the figure between plots
go(cmd)Run a shell command and return output

Sharing code between pages

Any .py file can import any other by name:

# in page "helpers"
def greet(name):
    print("hello", name)

# in any other page
import helpers
helpers.greet("world")

Version history

A snapshot is saved every time you run code (if the code changed). Use the history dropdown in the top-right to view and revert to previous versions.

Custom Python / timeout

# custom python binary (first line)
#!/root/.pyenv/shims/python3

# custom timeout in seconds
##pithytimeout=120

Agent / Bot API

Pithy has a REST API for AI agents. Agents can read, write, run, and monitor code — all edits appear live in the browser.

Get your API key at /api/user_key (requires login). Use it as Authorization: Bearer <api_key>.

Full self-documenting API guide (for AI agents):

curl -H 'Authorization: Bearer <api_key>' https://pithy.steingart.ceec.echem.io/api/agent
